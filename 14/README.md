# Or-Channel Function (L2.14)

Реализация функции `or`, которая объединяет один или несколько каналов сигнала завершения (`done`) в один. Возвращаемый канал закрывается сразу после того, как **закроется любой из исходных каналов**.

---

# Возможности

- Объединение произвольного числа каналов.
- Возвращаемый канал закрывается при закрытии **любого** входного канала.
- Поддержка рекурсивного объединения для эффективной работы с большим количеством каналов.
- Идеально подходит для реализации таймаутов, отмен операций и сигналов завершения в Go.

---

# Функция `or`

Сигнатура:

```go
func or(channels ...<-chan any) <-chan any
```


Описание работы:

- Если каналов нет — возвращается nil.

- Если канал один — возвращается он сам.

- Если два — используется select для чтения из обоих.

- Если больше двух — рекурсивно объединяются две половины каналов и выбирается первый, который закроется.

# Заключение

Функция `or` позволяет легко объединять несколько сигналов завершения в Go. Она:

- минимизирует блокировки,

- поддерживает произвольное количество каналов,

- удобна для реализации таймаутов и отмен операций в многопоточной среде.
