# Grep Analog (L2.12)

Реализация упрощённого аналога утилиты `grep` на языке Go.

Программа читает текстовый поток (из **STDIN** или **файла**) и выводит строки, соответствующие заданному **шаблону** (подстроке или регулярному выражению).

---

# Возможности

Поддерживаются следующие флаги:

| Флаг | Описание |
|-----|-----|
| `-A N` | вывести **N строк после** найденной |
| `-B N` | вывести **N строк до** найденной |
| `-C N` | вывести **N строк контекста вокруг** найденной (`-A N -B N`) |
| `-c` | вывести **только количество совпадений** |
| `-i` | **игнорировать регистр** |
| `-v` | **инвертировать фильтр** (выводить несовпадающие строки) |
| `-F` | воспринимать шаблон как **фиксированную строку**, а не regex |
| `-n` | выводить **номер строки** перед результатом |

Поддерживаются **любые комбинации флагов**, например:

```
grep -C 2 -n -i pattern file.txt
```

---

# Поведение

Программа старается максимально повторять поведение **UNIX `grep`**.

Поддерживаются:

- контекст строк (`-A`, `-B`, `-C`)
- объединение перекрывающихся блоков
- разделитель `--` между блоками
- работа с **регулярными выражениями**
- работа с **STDIN**
- корректная обработка **начала и конца файла**

---

# Использование

### С файлом

```
go run ./cmd pattern file.txt
```

### Через STDIN

```
cat file.txt | go run ./cmd pattern
```

---

# Примеры

### Поиск строк

```
go run ./cmd error logs.txt
```

---

### Игнорирование регистра

```
go run ./cmd -i error logs.txt
```

---

### Вывод номеров строк

```
go run ./cmd -n error logs.txt
```

Вывод:

```
12:error occurred
45:error occurred again
```

---

### Контекст строк

```
go run ./cmd -C 2 error logs.txt
```

Выводит по **2 строки до и после совпадения**.

---

### Только количество совпадений

```
go run ./cmd -c error logs.txt
```

---

### Инвертированный поиск

```
go run ./cmd -v error logs.txt
```

Выводит строки **не содержащие `error`**.

### `cmd`

Точка входа программы.  
Обрабатывает аргументы командной строки и запускает выполнение.

---

### `internal/grepanalog/matcher.go`

Основная логика утилиты:

- парсинг флагов
- поиск совпадений
- обработка контекста
- форматирование вывода

---

### `internal/ringbuffer`

Реализация **кольцевого буфера**, используемого для хранения строк **до совпадения** (`-B`).

Буфер позволяет эффективно хранить последние `N` строк без перераспределения памяти.

---

# Особенности реализации

### Поддержка regex

По умолчанию шаблон интерпретируется как **регулярное выражение**.

Для фиксированной строки используется флаг:

```
-F
```

---

### Игнорирование регистра

Флаг:

```
-i
```

Реализован через преобразование строк к нижнему регистру.

---

### Контекст строк

Для хранения строк **до совпадения** используется **кольцевой буфер**.

Это позволяет:

- хранить только последние `N` строк
- избегать лишнего потребления памяти
- эффективно обрабатывать большие файлы

---

### Объединение блоков

Если контекст двух совпадений **перекрывается**, блоки **объединяются**, как в настоящем `grep`.

Разделитель:

```
--
```

выводится только между независимыми блоками.

---

# Обработка пограничных случаев

Программа корректно обрабатывает:

- совпадения в **начале файла**
- совпадения в **конце файла**
- **перекрывающиеся контексты**
- **пустые строки**
- **длинные строки**
