# Shell L2.15

Простой shell на Go с поддержкой встроенных команд, пайпов, редиректов и логических операторов.

## Возможности

- Встроенные команды:
  - `cd [path]` — смена текущей директории
  - `pwd` — вывод текущей директории
  - `echo [args...]` — вывод аргументов
  - `kill [pid]` — завершение процесса
  - `exit [code]` — выход из shell с кодом
- Поддержка пайплайнов (`|`)
- Логические операторы `&&` и `||`
- Перенаправление ввода и вывода (`<`, `>`)
- Подстановка переменных окружения `$VAR`
- Работа в интерактивном и пакетном режимах
- Обработка сигналов `Ctrl+C`

## Структура проекта

```
cmd/main.go — точка входа, запуск shell
internal/shell/
├── builtins.go — реализация встроенных команд
├── exec.go — выполнение внешних и пайплайновых команд
├── expand.go — подстановка переменных окружения
├── parse.go — парсер командной строки
├── shell.go — основной цикл shell
├── tokenize.go — лексический анализ строки
└── types.go — типы данных и структуры
```


## Установка и запуск

1. Клонировать репозиторий:

```bash
git clone https://github.com/vvigg0/wbtech-l2.git
cd wbtech-l2/15
```

2. Собрать и запустить shell:

```bash
go build -o myshell cmd/main.go
./myshell
```

3. Примеры команд

```bash
$ pwd
/home/user
$ cd /tmp
$ echo Hello World
Hello World
$ ls | grep go
main.go
utils.go
$ exit 0
```

# Примечания

- Встроенные команды обрабатываются напрямую, остальные выполняются как внешние процессы.

- Пайпы и редиректы корректно работают вместе с логическими операторами.

- Shell поддерживает базовую подстановку переменных, но не `${VAR}` синтаксис.
