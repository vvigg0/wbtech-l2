# L2.16 - wget (упрощённая реализация)

Утилита для зеркалирования веб-сайтов (аналог `wget -m` в упрощённом виде).

Программа скачивает HTML-страницы, ресурсы (CSS, JS, изображения и т.п.), рекурсивно обходит ссылки в пределах одного домена и формирует локальную копию сайта, пригодную для оффлайн-просмотра.

---

## Возможности

- загрузка HTML-страниц и вложенных ресурсов  
- рекурсивный обход ссылок с ограничением глубины  
- скачивание только в рамках одного домена  
- корректная обработка относительных и абсолютных ссылок  
- дедупликация - один и тот же URL скачивается только один раз  
- формирование локальной структуры каталогов по URL  
- переписывание ссылок внутри HTML на локальные относительные пути  
- параллельные загрузки с ограничением количества одновременных запросов  
- корректная остановка обхода без утечек горутин  
- таймауты HTTP-запросов  

---

## Структура проекта

```
cmd/wget/ - точка входа (CLI)
internal/wget/ - реализация краулера
```


Основные компоненты:

- **crawler** - координация обхода сайта, очередь задач, дедупликация URL  
- **loader** - HTTP-загрузка и сохранение файлов  
- **HTML-парсер** - извлечение ссылок и переписывание путей  
- **dispatcher** - безопасная очередь задач без deadlock  

---

## Алгоритм работы

1. В очередь помещается стартовый URL.
2. Воркеры параллельно скачивают страницы.
3. Если контент - HTML:
   - извлекаются ссылки и ресурсы,
   - ссылки переписываются на локальные пути,
   - новые задачи добавляются в очередь.
4. Если контент - ресурс:
   - файл просто сохраняется локально.
5. Обход завершается, когда:
   - не осталось задач в очереди,
   - и нет активных загрузок.

---

## Формирование локальных путей

URL преобразуется в файловую структуру:

| URL | Локальный путь |
|-----|----------------|
| `https://site.com/` | `index.html` |
| `https://site.com/about` | `about/index.html` |
| `https://site.com/css/app.css` | `css/app.css` |

Все ссылки внутри HTML заменяются на относительные, чтобы сайт корректно открывался оффлайн.

## Установка и запуск

### Сборка

```
go build -o wget ./cmd/wget
```


### Использование

```
wget [flags] <url>
```
Флаги:
- -w int количество одновременных - загрузок (по умолчанию 1)
- -d int глубина обхода:
- -1 - без ограничения
- 0 - только стартовая страница
- N - до N переходов по ссылкам
- -p path директория для сохранения (по умолчанию текущая)


### Пример:

```
wget -w 5 -d 2 -p ./mirror https://example.com
```

После выполнения в каталоге `mirror/example.com/` будет создана локальная копия сайта.

---

## Ограничения

- обход выполняется только в пределах одного домена  
- параметры query в URL игнорируются для предотвращения бесконечных обходов  
- не поддерживается анализ ресурсов внутри CSS (`url(...)`)  
- robots.txt не обрабатывается  
- не обрабатываются сложные конструкции (`srcset`, динамические ссылки JS)
