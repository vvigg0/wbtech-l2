# Cut Analog (L2.13)

Реализация упрощённого аналога утилиты `cut` на языке Go.

Программа читает текстовый поток (из **STDIN** или **файла**) и выводит указанные **колонки** строк, разделённые определённым символом.

---

# Возможности

Поддерживаются следующие флаги:

| Флаг | Описание |
|------|----------|
| `-f` | Номера полей, которые нужно вывести. Можно указывать диапазоны, например `1,3-5`. |
| `-d` | Символ-разделитель между колонками (по умолчанию табуляция `\t`). |
| `-s` | Игнорировать строки без разделителя. |
| `-file` | Имя файла для обработки. Если не указан, используется STDIN. |

Поддерживаются **любые комбинации флагов**, например:

```./mycut -f 1,3-5 -d "," -s input.txt```


---

# Поведение

Программа старается повторять поведение UNIX `cut`:

- Нумерация колонок начинается с 1.
- Поддержка диапазонов и отдельных полей.
- Игнорирование колонок, выходящих за пределы строки.
- Игнорирование строк без разделителя при флаге `-s`.
- Работа с STDIN и файлами.
- Эффективная обработка больших файлов через буферизированное чтение.

---

# Использование

### С файлом

```./mycut -file input.txt -f 1,3-5 -d "," -s```


### Через STDIN

```cat input.txt | ./mycut -f 2-4```


---

# Примеры

### Вывод 1-й и 3-5 колонок через запятую

```./mycut -f 1,3-5 -d ","```

### Игнорирование строк без разделителя

```./mycut -f 2-4 -s```


### Использование табуляции по умолчанию

```./mycut -f 1-3 input.txt```

Точка входа программы.  
Обрабатывает аргументы командной строки и запускает выполнение.

---

### `internal/cutanalog`

Основная логика утилиты:

- парсинг флагов
- разбор диапазонов и отдельных колонок
- фильтрация строк по разделителю
- вывод указанных колонок
- буферизация чтения для больших файлов

---

# Особенности реализации

- Колонки нумеруются с 1, внутренние индексы начинаются с 0.
- Проверка корректности аргументов и флагов.
- Диапазоны объединяются и сортируются, дубликаты удаляются.
- Если разделитель состоит из более чем одного символа, программа завершится с ошибкой.
- Эффективная работа с большими файлами через `bufio.Scanner` с увеличенным буфером (до 1 MB).
