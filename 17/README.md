# L2.17 — Утилита telnet (примитивный telnet-клиент)

## Описание

Данная программа реализует простой telnet-клиент для взаимодействия с TCP-серверами.

Утилита устанавливает TCP-соединение с указанным хостом и портом, после чего:

- всё, что пользователь вводит в **STDIN**, отправляется в сокет  
- всё, что приходит из сокета, выводится в **STDOUT**

Клиент завершает работу:

- при нажатии **Ctrl+D** (EOF во входном потоке)
- если сервер закрыл соединение
- если не удалось установить соединение в пределах заданного таймаута

Реализация использует конкурентный ввод-вывод через отдельные горутины.

---

## Используемые технологии

- Go
- пакет `net` — работа с TCP-соединением
- пакет `io` — потоковое копирование данных
- пакет `flag` — разбор аргументов командной строки
- пакет `time` — управление таймаутом подключения

---

## Сборка

```bash
go build -o go-telnet
```

## Запуск

```bash
./go-telnet -host HOST -port PORT [-timeout=10s]
```

## Параметры
- `-host` - адрес удалённого сервера
- `-port` - порт сервера
- `-timeout` - таймаут подключения(по умолчанию 10 секунд)

---

## Пример использования

### Подключение к echo-серверу

```bash
./go-telnet -host tcpbin.com -port 4242
```

После подключения можно вводить произвольный текст - сервер будет отправлять его обратно

---
### Проверка SMTP-сервера

```bash
./go-telnet -host smtp.gmail.com -port 25
```

После подключения можно вручную отправлять команды SMTP:

```
HELO example.com
QUIT
```
